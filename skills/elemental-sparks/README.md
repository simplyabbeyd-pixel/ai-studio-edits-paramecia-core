# Elemental Sparks Skills

Experimental skill family for separating scientific fact from metaphor while deriving candidate Paramecia Sparks, Ideas, and Notions from elemental behavior.

## Scientific method

Each element begins at its smallest rediscoverable base:

1. **Identity** — atomic number, element, symbol, group.
2. **Observed function** — what the material or element actually does in the chosen system.
3. **Parameters** — conditions under which that function succeeds.
4. **Limitations** — where the function fails or changes.
5. **Compatibility** — what it can interact with directly.
6. **Assistance** — what other element/material/process is required when direct function is insufficient.
7. **Pure function** — a minimal side-effect-free rule that can be rerun at any scale.
8. **Metaphor** — only after the scientific layer is recorded.

## Reset rule

If a discovery path becomes too large or muddied, return to:

`IDENTITY -> OBSERVED FUNCTION -> PARAMETERS -> LIMITS -> COMPATIBILITY -> ASSISTANCE`

No metaphor may overwrite the scientific layer. No candidate Spark is canon merely because it is useful.
